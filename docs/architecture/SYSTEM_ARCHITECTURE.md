# System Architecture

## Main subsystems

- Airframe and propulsion
- Thrust-vector / tilt actuation
- Power distribution
- Flight controller
- Companion computer
- Navigation and state estimation
- Sensor payload
- Communication links
- Safety and arming

## Key design principle

The main body attitude and the translational thrust vector should be controlled as independently as practical. The exact mechanism may evolve between tilting motors, vectoring nozzles/rotors, or another propulsion layout.
