# Test Plan

## Phases

1. Mechanical fit and range-of-motion test
2. Power-system bench test
3. Actuator calibration
4. Sensor calibration
5. Software-in-the-loop test
6. Hardware-in-the-loop test
7. Restrained propulsion test
8. Tethered hover
9. Free hover
10. Level-body translation tests
11. Transition / forward-flight tests
12. Endurance and failure-mode testing

Record configuration, firmware version, battery, propeller, payload, weather/environment, and result for every flight test.
