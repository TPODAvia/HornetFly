# HornetFly Project Vision

HornetFly is a VTOL UAV platform focused on five design priorities:

1. VTOL operation.
2. High agility.
3. High forward speed.
4. Long-range / high-endurance flight.
5. Autonomous autopilot operation.

A distinguishing research goal is to reduce unnecessary movement of the central fuselage by using propulsion/control architectures capable of generating translational force without requiring the entire aircraft body to follow the same tilt angle.

The aircraft should support both:

- near-level body flight for sensing, mapping, inspection, communications, and payload stability;
- commanded body-angle flight when aerodynamics, maneuverability, or mission requirements benefit from it.
